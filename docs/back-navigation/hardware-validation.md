# 中文实机验收步骤

本会话没有连接或刷写设备。候选版本为 `1.6.5-weather.0.2.0-back.1`。由使用者自行通过此前已验证的应用固件更新入口安装相应 application bin；先按固件目录 SHA256SUMS 校验。不要把它当成原厂整机恢复镜像，也不要使用构建产生的 factory 合并镜像或默认 PlatformIO upload。

## 记录方式

每条记录：版本、主题、界面缩放、方向、页面、起点/移动方式、期望父页面、实际结果、是否处于刷新中。用视频或秒表分开记录“触摸抬起 → 导航响应/旧页面结束”与“新页面墨水完全稳定”；若只能看到墨水变化，记为端到端时间，不声称软件耗时。

可用表：编号 / 场景 / 结果（通过、失败、未测）/ 时间 / 备注。主机报告不会替使用者勾选。

## 最短验收

1. 关于核对完整版本后，依次进入设置 → Wi-Fi → 手动连接 → 密码键盘。点顶部箭头应立即开始取消流程，不再出现键盘吞掉返回；再试自动连接中取消。密码不应进入日志。
2. 在三级文件目录逐层打开。点箭头中心、左右边缘和下沿各 10 次，每次只退一级。慢点按 300/800/1100ms 仍只退一级；按住 1.2s 以上不触发屏幕返回。真实实体 Back 长按仍执行原功能。
3. 在箭头上按下，移动 10–20px 后抬起应返回；明显拖开 35px 以上、拖开再拖回、竖向滑动或多指接触应不返回。图标附近状态栏空白应只按原规则打开前光，列表第一行应不误返回。
4. 设置任一列表项已选中时点顶部箭头，应保存设置回首页。书库有搜索条件时第一次返回清搜索；分组折叠时先恢复；普通列表选中时点击返回应回首页。实体键的标签焦点步骤保留。
5. 打开通用确认、删除确认、OTA 确认与清缓存确认。顶部/实体/左边缘返回都只取消最上层，不执行确认。清缓存取消后必须真正离开警告页，缓存不应被删除。
6. 持续返回只在每次独立点按时退一层。旧页面按住期间通过其他允许的输入切页，随后抬起不应激活新页面。快速双击也不应把第一次旧接触的抬起重复应用。
7. 在刚进入页面、首帧仍绘制、列表刷新进行中分别点按。首帧尚未发布时不会追认在旧画面上的点击，待新画面出现后再点；普通重绘跨按下/抬起应有效，不能要求按下时额外全刷。
8. 阅读 EPUB/TXT/XTC：记录当前页，打开菜单/目录/书签/进度、脚注与词典后取消，检查原位置。进入脚注后返回应退回脚注前位置。正文边缘翻页规则保持；不要把正文无顶部箭头当成故障。
9. 应用菜单 → 计数器：修改后返回重开，检查持久化。天气 → 城市/省份逐层取消；精确位置每一步取消不应提交半份配置。天气底部返回/刷新之间的空白应无动作，底部返回应退出并停止当前请求。
10. 四主题、四方向和实际可用的各 UI 缩放复测。重点检查安全区、长中文标题、右侧搜索/刷新、天气横屏，以及前光面板拖动后的返回。

## 关键状态与睡眠

- USB 主机已独占存储时不应出现返回箭头；实体/手势也不得绕过独占退出。正确弹出或断线仍走原重启规则。先在不写文件的状态验证，切勿把强行打断写入当成验收。
- 固件真正写入阶段不提供返回或切页；失败后可返回，恢复模式可重新选择固件。仅为测试返回功能没有必要反复执行固件写入。
- 同步 NTP、认证、OTA 元数据查询等忙碌期没有可用箭头，仍可能等待底座网络超时；记录最坏时间。它们是已知响应限制，不是已证明的硬件故障。
- 从正文休眠并唤醒，先松开唤醒键，再打开菜单并返回；从天气息屏唤醒检查原阅读恢复/首页规则。检查前光、天气定时更新和低电量保护。0.2.0 的息屏/长篇/天气实测尚未完成，本次不能据主机测试标记通过。
- 连续进入/返回 50 次检查阅读位置、应用状态和可用堆/最大块是否持续下降；若需日志，沿用串口的 ACT/WIFI/WX 日志，不在热循环向 SD 写诊断。

失败时保留候选版本、页面与复现动作；优先提供录像和是否跨刷新信息。不要只记录“返回无效”，这样无法区分触摸采样、导航栈等待与墨水波形耗时。
