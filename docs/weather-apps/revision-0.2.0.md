# 0.2.0 修订与验证

基线仍为 CrossPoint 1.6.5。设备现已安装 0.2.0，用户确认版本与默认中文；此前 0.1.1 的计数器持久化及前台天气正常；
0.1.1 的天气息屏未通过，读取到的天气设置为 `enabled:false`，缓存有效，无崩溃报告。
0.2.0 的实机状态见交付目录 `device-validation.json` 和 `ota-install-progress.json`。

## 本次改动

- 565 个界面词条全部提供简体中文，校验占位参数及交付字体字形。新安装默认中文；
  已有安装首次升级到本版自动切换中文，写入迁移标记后保留后续手动选择。
- TXT 冷打开仅排当前可见页，不再在开书阶段同步建立全书页码。按阅读进度追加偏移，
  v4 索引每页只追加新偏移，兼容原 v3 完整索引。未读完时总页数以 `~` 标明估计值；
  到达末尾后为精确页数。长按跳页仅计算至多十页的所需前缀。阅读位置沿用原格式。
- 状态栏明确显示无线已连接、未连接或关闭。Wi-Fi 列表常驻“重新扫描网络”，显示扫描中、
  完成及失败提示；天气网络配置展示连接成功页面，点击完成后返回。
- 天气菜单提供精确位置：依次输入 WGS84 纬度、经度和地点名称。经纬度保留五位小数，
  以整数 E5 保存；位置身份基于该整数生成，避免 JSON 浮点回读改变位置身份。
  地点名称键盘沿用底座支持的输入布局，可保留当前城市中文名；不包含中文拼音输入法。
  手动位置替代城市中心点查询坐标；天气服务仍为模型网格预报。切换位置清空当前显示，
  关闭自动更新，必须重新成功获取一次才能开启；旧位置缓存不会被新位置采用。
- 天气息屏开关加“已开启／已关闭”说明，保存失败回滚并提示。开始刷新时一次快速刷新，
  最终结果一次完整刷新；同状态重复通知不重绘。定时唤醒更新期间保留原墨水屏画面，
  完成后全刷一次。天气视图不会被 Wi-Fi 状态通知反复触发绘图。
- 天气配置页面可保留刚建立的连接；获取完成或退出天气模块时关闭无线。

## 已执行主机验证

- X4 Pro release 目标构建通过；应用镜像小于原 6,553,600 字节应用分区；镜像校验通过。
- 原有 378 项 CTest 回归全部通过。
- 直接编译生产 TXT 阅读代码，使用内存 HAL/绘图适配器：约 3 MB 书首屏只读一次 8 KB，
  约 0–1 ms 主机布局；续读、前后翻页、十页跳转、结束状态及损坏缓存验证通过。
  **该时间不含实机存储卡、字体加载或墨水屏波形，不是设备毫秒级打开的验收结果。**
- 天气模型、JSON、坐标解析、E5 位置身份、原子缓存、开关保存失败回滚、位置更换和低电量
  滞回通过 UBSan；精确位置保存重载及已开启开关重载通过。重复更新通知 1000 次不产生新绘图请求。
- 英中天气布局共 36 场景边界检查；565 项翻译覆盖、格式参数及字体字形检查通过。
- cppcheck 高/中等级问题为 0，保留 2 个低等级样式建议。macOS ASan 限制见主验证报告。

## 实机复测顺序

1. 关于版本为 `1.6.5-weather.0.2.0`；检查中文菜单、Wi-Fi 扫描按钮及状态提示。
2. 打开原长篇 TXT，记录首次看到正文和再次打开的耗时，前后翻页、退出再开检查进度。
3. 保存精确经纬度及名称，刷新天气；观察请求期间画面稳定、结果完成后一次全刷。
4. 明确看到息屏选项下方“已开启：休眠时显示天气”，退出再进确认仍开启；从书页休眠，
   检查天气画面、前光关闭和按电源键返回原页。未通过前不宣称天气休眠已修复。
5. 真实 30 分钟周期、断网缓存、低电量、断电、反复应用切换及 24 小时功耗仍需继续实测。

本版未验证完整原厂恢复路径；用户此前已明确授权在该条件下继续安装。
