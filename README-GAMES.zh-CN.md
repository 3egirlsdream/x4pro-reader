# X4 Pro 离线原生游戏

本目录是独立源码副本：CrossPoint 1.6.5 + 已有 weather.0.2.0 扩展 + 2048 / 五子棋 / 扫雷。
三款 C++ 应用编入 X4 Pro 固件，从“首页 → 应用 → 2048 / 五子棋 / 扫雷”分别打开，离线运行。
它们不是 XTOS 可单独复制安装的应用包。默认语言沿用天气版的简体中文设置。

固件版本：`1.6.5-weather.0.2.0-games.0.2.0`。
本版固件及校验值在上级 `firmware/games-0.2.0/`，扫雷测试记录见 `docs/games/minesweeper-validation.zh-CN.md`；初版记录见 `docs/games/validation.zh-CN.md`。

## 操作

### 通用

- 进入时使用竖屏布局，尺寸与安全区域由渲染器/主题提供；返回、Home 或休眠退出后恢复进入前的方向。
- 底部“返回”回到应用菜单；可用的返回实体键作用相同。系统 Home 保持系统设置的行为。
- 底部“菜单”或长按侧面下键 700 毫秒打开游戏菜单；侧面上下键选择，确认键执行，也可触摸菜单项。
- “继续游戏”关闭菜单。“新游戏”会替换本应用当前进度；五子棋的新局菜单可选“我先手”或“电脑先手”。
- 退出或系统休眠时，仅在棋局有变化时保存；再次打开恢复棋盘。思考中退出保存的是尚未落下 AI 棋子的局面，重开后重新搜索。
- 无动画，无定时重绘。落子/选点/菜单发生变化才请求绘制；首次与每累计 12 次棋盘更新使用完整刷新，其余使用快速刷新。手动强制刷新仍可清理残影。

### 2048

- 在棋盘上向四个方向滑动；可用的左右实体键也可移动。
- 侧面上下键默认上下移动；确认键切换“上下 / 左右”轴，以便只有两枚方向侧键的机型操作。
- 相同数字每步只合并一次，新增数字为 2（约 90%）或 4（约 10%）。无效移动不加分、不生成数字、不请求刷新。
- 顶部显示分数；达到 2048 后直接继续。无合法移动时显示结束，从菜单开始新局。
- 分数为饱和 32 位无符号值；数字支持至 2³¹，该值不再合并，以避免整数溢出。

### 五子棋

- 默认 15×15 自由规则：无禁手，任一方向五连及以上获胜，满盘无胜者和棋。黑先白后。
- 方框是当前选点。首次点选一个交点显示方框，再点相同交点落子；初始中点已有方框，可直接落子。点在交点半格范围内会吸附到最近交点，棋盘外触摸无效。
- 确认键在当前方框处落子；侧面上下键按顺序前后移动选点（跨行），可用左右键在行内移动。占用点或非本人回合不落子。
- 黑子为实心，白子为空心；最后落子用反色小方点标记。五个星位辅助定位。
- 电脑思考时仍可打开菜单、返回、Home 或休眠；菜单暂停并取消当前搜索，继续时从当前棋盘重新搜索。

### 扫雷

- 默认初级 9×9 / 10 雷；菜单可新开中级 12×12 / 24 雷，或高级 15×15 / 45 雷。
- 首次实际翻开时才生成雷区，首格及周围八格保证无雷。未翻开前也可插旗；有旗的格子不会被翻开。
- 方框为当前选格。点选一格，再点同格执行当前模式；初始中格已有方框，可直接操作。
- 默认“翻开”模式；棋盘下方按钮切换“翻开 / 插旗”。长按格子可直接插旗/取消旗，不必切换模式。
- 侧面上下键前后逐格选点，可用左右键在行内移动；确认键执行当前模式。长按上键 700 毫秒切换插旗模式；长按下键打开菜单。
- 零周围的空白区域自动连开。翻开模式下，再操作已翻开的数字格，若周围旗数等于数字则打开其余邻格；错误插旗可能导致踩雷。
- 翻开全部非雷格获胜；踩雷后显示全部地雷、爆炸格及错误旗。顶部显示总雷数、已插旗数和已开格数，终局后从菜单开始新局。
- 棋盘、雷区、旗、难度和终局保存到独立 `game-mines` 目录；选框和操作模式重开后重置。保存、损坏恢复、退出方向和系统休眠沿用通用规则。

## 存档与资源

- 路径为 `/.crosspoint/apps/<id>/state.json`，三个独立 ID：`game-2048`、`game-gomoku`、`game-mines`。
- schema 1，固定长度二进制状态编码成十六进制 JSON 字符串；包括棋盘、分数/轮次、先后手及 2048 随机数状态，附 FNV-1a 内容校验。
- 校验版本、长度、数字/棋子范围、黑白数量、轮次、最后落子与终局合法性。损坏主文件会尝试 `.bak` / `.tmp`；均无有效状态则开始新局。
- 保存沿用 AppStorage 的临时文件及备份轮换，经 HAL 访问 SD 卡。只在改变后退出时写盘，突然断电可能丢失本次未退出的棋局；文件轮换保障完整旧状态可恢复，并非逐步自动存档。
- 模型、AI、编码缓冲固定大小，无搜索递归或循环中的动态分配。Activity 通过框架 `makeUniqueNoThrow` 一次分配，退出释放；存档验证/JSON 仅在进入退出时申请短期内存。
- 不创建后台游戏任务，不接管 Wi-Fi、电源或天气更新。系统天气休眠替换当前 Activity 时走相同退出/保存路径，唤醒仍遵循天气版回首页的约定。
- 日志 `GAME` 包含 Activity 大小、进入/退出可用堆及最大块、AI 节点数与累计计算时间，供实机验收采样。

## 构建和测试

```sh
# 安装 PlatformIO 6.2.0 后，在本目录执行；固定平台/SDK 见 platformio.ini 和 provenance。
pio run -e x4pro-gh_release
python3 scripts/test_games.py
python3 scripts/test_games_ui.py
python3 scripts/test_weather.py
python3 scripts/test_txt_paging.py
./bin/clang-format-fix -g
git diff --check
```

`test_games.py` 默认启用 UBSan（Linux 默认 ASan+UBSan），需要主机 C++20 编译器；存档测试使用构建时的 ArduinoJson 依赖。
UI 测试使用生产 Activity 与伪 HAL/输入/显示，可通过 `--font <X4ProSansSC-Regular.ttf> --output <目录>` 生成 PNG 和进行文字边界检查；需要 Pillow。
现有天气固件使用的 `X4ProSansSC` SD 字体继续复用，本游戏包不改写 SD 卡或字体。

源码基线与导入补丁的证据见上级 `firmware/games-0.2.0/provenance.json`。SDK 内容已随源码提供，版本固定到 `111fdcc7f0176c3ee38391a160ee296bf492dbd8`。
主机测试、交叉编译、内存布局验证已完成；未连接、刷写或运行阅读器。实际墨水屏残影、触摸精度、设备 AI 耗时、耗电、连续进入退出与天气定时休眠仍须按验收记录实测。
